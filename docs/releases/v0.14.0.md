# v0.14.0 — 侧边栏直接编辑与 AI 修改记录协同、右侧栏选区右键菜单、一体化「音浪圆球」轮盘与分类拖拽排序

<!-- aw-compat: agy=2.34.x -->

### 更新亮点

- **新增侧边栏直接编辑文本文档与 AI 修改记录协同**：
  - **默认不打扰官方视图，按需一键切入编辑**：在右侧边栏打开 `.md`、`.txt`、`.json`、`.jsonl`、`.yaml`、`.csv`、`.js`、`.ts`、`.py` 等可编辑文档时，默认保持 Antigravity 官方展示不变；点击顶栏「**编辑**」按钮（或在右侧栏选中文字后通过右键菜单进入）即可展开带行号、查找替换（`Ctrl + F` / `Ctrl + H`）、自动换行与 JSON 格式化的一体化编辑器，随时可「退出编辑」恢复官方视图。
  - **自动保存、JSON 未闭合保护与外部修改冲突守卫**：停笔约 `0.65` 秒自动原子写入磁盘（保留原换行符与编码，非 UTF-8 转换自动留存 `.bak.encoding` 备份），亦可随时 `Ctrl + S` 立即保存；编辑 `.json` / `.jsonl` 括号或引号尚未闭合时自动暂停写入防损坏文件，补全后立刻恢复保存（同时提供按需强制保存）；若外部程序或 AI 刚更新过该文件，自动拦截覆盖并提示重载或确认覆盖；敏感凭据文件（如 `.env`）严格禁止编辑。
  - **内置修改差异抽屉 + `anchor-wheel-edits` 技能**：每次保存自动生成带行号的统一差异（`unified diff`）并持久化至 `RECENT_USER_EDITS.md`；既可点开顶栏「**修改记录**」一键「**发给 AI 查看**」自动填入聊天输入框，也可直接在对话里问 AI「看看我刚才在侧边栏改了什么」，由内置技能自动读取你的修改记录。

- **新增右侧边栏选区快捷右键菜单（严格隔离，零冲突）**：
  - 仅在**右侧边栏**划选普通文档正文或代码片段后单击右键时弹出，支持「**复制选中内容**」「**引用选中片段到输入框**（自动附带 `@文件名` 与行号）」「**进入编辑并定位到此段**」及「**复制文件路径**」；按住 `Shift + 右键` 可随时放行浏览器原生菜单。
  - 严格排除左侧对话消息气泡及文件链接胶囊，与 `obsidian-prism` 链接右键菜单零冲突共存。

- **全新一体化「音浪圆球」专属主题与轮盘动态外观**：
  - **轮盘扇区本体实时有机形变**：彻底告别硬边静态圆饼外贴细线的割裂感——开启音浪后，双侧轮盘、经典轮盘与窗口布局轮盘的扇区外沿及内环本身会随声波谐波平滑起伏呼吸；光标停在圆心时沉稳律动，偏向任一侧时对应侧扇区物理鼓起涌动，与三层交错编织的液态音浪膜、扇区内部同心扩散声波涟漪及圆心驻波谐振环无缝融合（浪峰经 `tanh` 软饱和严控在安全高度上限内，二级子列表展开方向自动避让不挡字）。
  - **浅灰/深色背景双高对比 + 按主题独立记忆**：新增「**音浪圆球（深色动态）**」专属深海矿石黑曜球面主题（海青碧向暖琥珀/珍珠高光过渡，悬停在浅白代码页上同样清晰立体，无廉价蓝紫霓虹）；「深空黑曜」「暖炭玄岩」「白昼冷晶」「暖白画册」四套主题默认保持经典简洁，按需在「设置 → 收纳与高级 → 界面外观」中独立勾选开启并按主题分别记忆开关状态。

- **双侧轮盘分类拖拽排序、代码扩展名默认归类与交互细节修复**：
  - **手柄上下拖拽重排分类**：在「设置 → 分类与预览」中按住每条分类行左侧六点手柄（`⋮⋮`）即可上下拖动调整双侧轮盘扇区顺序，上方轮盘图解毫秒级同步重排，底部「其他」固定兜底。
  - **代码文件默认归入「文档」分类**：新增 `.js`、`.mjs`、`.cjs`、`.ts`、`.tsx`、`.jsx`、`.py` 等常见代码扩展名至默认「文档」规则，并对旧配置执行一次性无损迁移（后续手动修改后不会重复改回）。
  - **多项高感知体验修复**：修复在 Antigravity 原生 `.js` 代码视图点击顶部「**编辑**」按钮被宿主全高容器遮挡的问题；移除「收纳与高级」页顶部容易误导用户的旧轮盘示意图，并将外观配置区更名为「**界面外观**」。

### 安装与升级

- **AGY Market 用户**：可直接在 AGY Market 侧栏检测更新并一键安装预构建 `.tar.gz` 发行包（自动通过 `.sha256` 校验并完整保留 `data/` 个人分组与设置）。
- **手动安装 / 升级**：下载下方 `agy-anchor-wheel-v0.14.0.zip`，解压后 Windows 用户双击 `install-plugin.cmd`、macOS / Linux 用户运行 `bash install-plugin.sh`，脚本会自动备份旧版并无损升级（保留 `data/`）；更新后在 Antigravity 插件管理列表将「锚点轮盘 · AnchorWheel」关闭再重新开启一次即可加载新版后台服务与内置编辑记录技能。
- **适配 Antigravity**：`2.34.0`（`2.34.x` 已实测，本地需 Node.js >= 22，推荐 >= 22.5 以启用 SQLite 预览；可选安装 `ffmpeg` 解锁 ProRes / HEVC / MKV / AVI 等视频自动转码与透明棋盘格预览）
