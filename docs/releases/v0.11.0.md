# v0.11.0 — 12-bit 透明 .mov 棋盘格直览、聊天链接防覆盖、Adobe 工程轻量预览与跨平台安全加固

<!-- aw-compat: agy=2.34.x -->

### 更新亮点

- **12-bit ProRes 4444 透明 `.mov` 彻底修复黑屏与伴生插件接管**：
  - **透明通道自动叠合成棋盘格**：识别带 Alpha 通道的 ProRes 4444 / 10~12-bit 透明视频，在视频转码流、播放前 640px 海报帧与 0.25 秒悬停动态 WebP 快览中统一叠合深灰棋盘格底纹，避免播放前与播放中出现纯黑底。
  - **兼容探测自动接管伴生视图**：当同时安装 `obsidian-prism` 等伴生插件且其内置视频播放器无法解码 ProRes / HEVC / 10-bit / MKV / AVI 等编码时，AnchorWheel 通过 `probeVideo` 与 `<video>` 报错检测自动接管渲染（常规 H.264 MP4 / WebM 仍继续友好避让）；手动点击预览按钮后的状态不再被后续刷新误关。
  - **缺失 `ffprobe` 与大体积 ProRes 兼容**：仅装单文件 `ffmpeg` 时自动通过 `ffmpeg -i` 回退解析画幅、编码与透明通道；放宽短时长高码率中间编码的缓存转码体积上限，并保留无 `ffmpeg` 环境下的系统播放器一键打开兜底。

- **彻底解决聊天区域点击文件覆盖右侧边栏标签页**：
  - 自动将 Antigravity 右侧边栏 `sidePanelV2` 中处于临时预览态（`isPreview: true`）的标签页提升为持久标签，无论从对话区文件链接、Artifact 卡片还是工作区列表点击文件，均不再顶替原有标签页。
  - 在「设置 → 标签组收纳与外观」中提供「**防聊天链接覆盖已有标签页**」独立开关（默认开启，可按需关闭）。

- **零依赖、有界读取的 Adobe 工程与素材侧边栏预览**：
  - 新增 `adobe_formats_renderer.mjs`，采用文件描述符分段读取与严格体积/解析上限控制（数百 MB 大工程毫秒级秒开、不拖慢侧边栏）：
    - **Photoshop (`.psd` / `.psb`)**：内嵌合成缩略图、画布尺寸、色深与 DPI、ICC 配置文件、引用字体与图层结构（含 8/16/32-bit `Lr16`/`Lr32` 图层及旧版中文图层名 GB18030 解码回退）。
    - **After Effects (`.aep` / `.aepx`)**：缓冲分页 RIFX 区块扫描，提取合成列表（画幅/帧率/时长/图层数）、导入素材路径、脚本表达式摘录与尾部 XMP 版本信息。
    - **Premiere Pro (`.prproj`)**：标准 `zlib` 有界前缀解压，精准解析工程版本、时间线序列（自动关联 `<VideoTrackGroup>` 回填分辨率与帧率）、视音频轨数与媒体素材清单。
    - **Illustrator (`.ai`)**：PDF 兼容 `.ai`（≤ 24 MB）直接渲染完整矢量 PDF 预览；超大或旧版 PostScript / EPS `.ai` 提取画板与 XMP 概要。
    - **动态图形模板 (`.mogrt`)**：基于 `fd` 尾部中央目录按需解压（突破 32 MB 限制），提取封面图、真实分辨率/帧率/时长、来源引擎、使用字体与中文化可编辑控件表。
    - **字幕样式与调色/音频/排版**：支持 `.prtextstyle`（含字体识别与可选 gzip 兼容）、`.sesx`（Audition 多轨与素材列表）、`.indd`（校验魔数 + XMP 首页缩略图与排版概要）、`.cube`（按需切换 1D/3D LUT 8 组标准色卡前后对比，支持 `DOMAIN_MIN/MAX` 归一化）。

- **跨平台（macOS / Linux / Windows）移植性与安全加固**：
  - **安全修复**：修复 `.ipynb` 输出图表 Base64 属性注入风险；为 `/api/file/raw` 增加强制 `mediaToken` 校验、体积上限、`Content-Security-Policy: default-src 'none'; sandbox` 与 `X-Content-Type-Options: nosniff` 响应头；CORS 移除 `Origin: null` 与任意 `file://` 放行；敏感文件屏蔽清单增补 `.npmrc`、`.pypirc`、`.netrc`、`.git-credentials` 与 `mcp_config.json`。
  - **跨平台修复**：修正 POSIX 路径分隔符、`file://` URI 中 `#` / `?` 特殊字符转义及 macOS/Linux 血缘键大小写匹配；兼容 Linux GNU `tar` 与 `.7z` / `.rar` 外部工具级联列清单；SQLite 启用有界 16 字节头校验（支持 >32 MB 数据库与只读目录 WAL 回退）；补齐 Mode 1 编码重解码浮层内的链接跳转与代码复制；支持 macOS `Cmd+[` / `Cmd+]` 历史翻页与 Linux Flatpak LibreOffice 探测。
  - **跨平台安装脚本**：新增 `install-plugin.sh`（支持 Homebrew / nvm / fnm / volta / mise / asdf）与 `.gitattributes` 行尾锁定。

### 安装与升级

- **AGY Market 用户**：可直接在 AGY Market 侧栏检测更新并一键安装预构建 `.tar.gz` 发行包（自动通过 `.sha256` 校验并完整保留 `data/` 个人分组与设置）。
- **手动安装 / 升级**：下载下方 `agy-anchor-wheel-v0.11.0.zip`，解压后 Windows 用户双击 `install-plugin.cmd`、macOS / Linux 用户运行 `bash install-plugin.sh`，脚本会自动备份旧版并无损升级（保留 `data/`）；更新后在 Antigravity 左侧「自定义扩展」将「锚点轮盘 · AnchorWheel」关闭再重新开启一次即可加载新版后端。
- **适配 Antigravity**：`2.34.0`（`2.34.x` 已实测，本地需 Node.js >= 22，推荐 >= 22.5 以启用 SQLite 预览；安装 `ffmpeg` 可解锁 ProRes / HEVC / MKV / AVI 等非标准编码视频自动转码与透明棋盘格预览）
