# v0.9.0 — 真实版式幻灯片画布、官方原生视觉对齐、宿主升级自动避让与全场景格式扩展

<!-- aw-compat: agy=2.34.x -->

### 更新亮点

- **真实 2D 空间版式幻灯片渲染 + 可选本机引擎无窗精绘（`.pptx` / `.ppsx` / `.potx` / `.ppt` / `.odp`）**：
  - 彻底告别旧版将幻灯片拆成纯文本条目卡的近似方案：内置零依赖 OOXML / DrawingML 二维坐标渲染引擎，完整解析主题色板（`theme1.xml` 含明度与透明度变换）→ 母版（`slideMaster` 背景与字号基准）→ 版式（`slideLayout` 占位符坐标继承）→ 单页幻灯片四层结构，按原稿真实长宽比（`16:9` / `4:3` 等）在侧边栏等比缩放呈现文本框、组合图形（`<p:grpSp>`）、图片裁切（`srcRect`）、SVG 几何图形与箭头、定位表格、原生 `<c:chart>` 柱状/折线/饼图及 SmartArt 结构图。
  - **可选一键「本机精绘」兜底**：针对含复杂动画叠层或旧版二进制 `.ppt` 的文件，工具栏提供按需触发的「**本机精绘**」按钮，在后台无窗口、零焦点抢占调用本机 LibreOffice / PowerPoint / WPS 导出 1:1 高清幻灯片画面并本地缓存，随时可在矢量画布与原稿画面间切换。

- **去公式化 AI 味 · 全面对齐 Google Antigravity 官方界面风格**：
  - 移除旧版阅读器顶部的彩色胶囊角标、重复堆叠的粗体文件名横栏、外层套壳卡片边框、高亮彩色列表序号与醒目黄底横幅。
  - 直接复用 Antigravity 官方字体栈（`Google Sans Flex` / `Google Sans Code`）与原生表面变量（`--background` / `--content` / `--border` / `--muted-foreground`）：默认阅读态采用无外框平铺版面（需要核对排版时可点「纸面」切换 A4 白纸视图）；在原生侧边栏（Mode 1）保留宿主自带的面包屑路径与右上角 `⋮` 更多操作栏，电子表格与数据库直接将工作表标签内联进单行细线工具栏，窄视口（`390px`）自动收敛为纯图标零横向溢出。

- **面向未来的「宿主原生优先自动避让」机制（Native-First Auto-Yield）**：
  - 不再仅凭文件后缀硬性覆盖侧边栏：实时检测宿主 `fileView` 容器的真实渲染状态，仅当 Antigravity 显示不可预览占位提示（或对 `.ipynb` / `.eml` / `.obj` / `.stl` 仅展示原始源码）时才自动接管渲染。
  - 若未来新版 Antigravity 原生支持了某类办公文档或 PDF 的富视图预览，或已由伴生插件完成渲染，AnchorWheel 会自动退让、不遮挡官方画面，仅在伴生条保留低调的按需切换入口（亦可在「设置 → 分类与快览 → 富文档自动接管策略」中自由切换策略）。

- **全场景文件格式扩展与存量解析缺陷修复**：
  - **办公与邮件补完**：旧版 Excel `.xls`（支持 BIFF8 二进制工作簿、HTML 伪装表与 XML 2003 表格）、旧版 `.ppt` 二进制幻灯片、Word/Excel/PPT 模板（`.dotx` / `.xltx` / `.potx` / `.ppsx`）、`.eml` 邮件原件（RFC 2047 中文编码头与多段正文净化）及 Mode 1 + Mode 2 双端安全 Blob `.pdf` 内嵌预览。
  - **研发与数据文件**：Jupyter / Colab 笔记本 `.ipynb`（Markdown 大纲、代码单元、过滤 ANSI 转义的输出流与内嵌图表）、SQLite 数据库 `.sqlite` / `.sqlite3` / `.db`（基于 Node 原生只读 `node:sqlite` 浏览多表结构与前 300 行记录）、`.jsonl` / `.ndjson` 结构化记录表。
  - **三维模型、字体、字幕与归档包**：交互式三维白模 `.glb` / `.stl` / `.obj`（零 WebGL 依赖、60fps Canvas 实体光影与线框切换、左键旋转与滚轮缩放，大模型自动均匀抽稀防卡顿）、字体样张 `.ttf` / `.otf` / `.woff` / `.woff2`（OpenType 字体名解析与自定义试打字号瀑布流）、字幕歌词时间轴 `.srt` / `.ass` / `.ssa` / `.vtt` / `.lrc`（按需切换干净时间轴表）、多格式归档清单 `.tar` / `.tar.gz` / `.tgz` / `.7z` / `.rar`。
  - **关键缺陷修复**：修复 OOXML `<mc:AlternateContent>` 导致 Word/PPT 文本框重复提取两遍的问题；补齐 Word `theme1.xml` `w:themeColor` 主题色解析；过滤 Excel `<rPh>` 拼音注音对中文单元格的污染并支持百分比格式；修复文件在磁盘修改保存后侧边栏重开仍命中前端旧缓存的问题。

### 安装与升级

- **AGY Market 用户**：可直接在 AGY Market 侧栏检测更新并一键安装预构建 `.tar.gz` 发行包（自动通过 `.sha256` 校验并完整保留 `data/` 个人分组与设置）。
- **手动安装 / 升级**：下载下方 `agy-anchor-wheel-v0.9.0.zip`，解压后双击 `install-plugin.cmd` 即可自动备份旧版并无损升级；安装后在 Antigravity 左侧「自定义扩展」将「锚点轮盘 · AnchorWheel」关闭再重新开启一次即可加载新版后端。
- **适配 Antigravity**：`2.34.0`（`2.34.x` 已实测，本地需 Node.js >= 22.5）
