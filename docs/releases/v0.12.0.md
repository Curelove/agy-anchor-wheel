# v0.12.0 — Quicker / 鼠标手势防冲突触发组合、自由快捷键录制与「按住松手」轮盘

<!-- aw-compat: agy=2.34.x -->

### 更新亮点

- **彻底化解与 Quicker、鼠标手势软件及无中键设备的触发冲突**：
  - **「修饰键 + 鼠标按键」自由组合**：在「设置 → 交互模式与图解 → 鼠标触发按键」中，支持为鼠标中键、右键、侧键 1、侧键 2 及空白区左键叠加可选修饰键（`无修饰 / Alt (macOS 自动显示 Option) / Shift / Ctrl`）。例如设置为 `Alt + 右键` 或 `Alt + 中键` 后，裸按中键与裸按右键 100% 放行给 Quicker、MouseInc、WGestures 或宿主菜单，互不抢占。
  - **笔记本触控板与无中键鼠标原生适配**：支持在正文空白处按住 `Alt / Shift / Ctrl + 鼠标左键` 呼出轮盘（选择左键且无修饰时自动升级为 `Alt + 左键` 防误吞常规点击；在链接上点击仍保留原有跳转行为）。
  - **右键原生菜单逃生口**：无论处于何种右键配置下，按住 `Shift + 右键` 均可强制透传打开 Antigravity 宿主原生右键菜单，不再被插件自绘资源管理器菜单遮挡。
  - **三档触发灵敏度与防误触微调**：在设置列表底部的折叠区「进阶手势与防冲突微调」中提供「**跟手 / 均衡 / 防误触**」三档预设（动态调整长按毫秒数与拖拽像素阈值），减少高 DPI 鼠标短按误弹轮盘。

- **自定义快捷键录制器 +「按住快捷键原地呼出、松开即确认」**：
  - **所按即所得的键帽录制器**：告别固定 4 项快捷键下拉，点击设置中的键帽按钮即可直接按下录入 `Tab`、波浪键 `` ` ~ ``（中文输入法及 macOS Option 死键下均按物理键码精准匹配）、`F1–F12` 或任意修饰组合键（如 `Alt + E`、`Ctrl + Shift + W`）；自动拦截单字母/空格误录，录制态按 `Esc` 仅取消录制、不误关设置窗口。
  - **零鼠标按键冲突的「按住松手」呼出模式**：新增快捷键呼出方式切换（`按一下开关` ⇄ `按住松手`）。切为「按住松手」后，按住快捷键时双侧轮盘/经典轮盘直接在**当前鼠标光标处**原地弹出（竖向层级树亦支持悬停松开即跳转），移动鼠标划选目标、松开快捷键立刻打开并收起（组合键无论先抬主键还是先抬修饰键均干净收尾，并屏蔽系统长按连发闪烁）。
  - **便于外部效率工具联动**：Quicker、罗技 G Hub、AutoHotkey 等工具可直接向 Antigravity 发送上述自定义快捷键，实现与锚点轮盘的双向联动。

- **移除硬编码 `Alt + Q` 抢占与设置页清爽整合**：
  - 移除 Mode 1 原生脚本中遗留的硬编码 `Alt + Q` 强制监听，仅在用户主动设置时才响应，不再与 QQ、翻译工具或 Quicker 面板暗中撞键。
  - 修饰键与鼠标键合并为单行紧凑组合、灵敏度与协作说明收进默认折叠区，不增加主视图行数；修改任意触发键、快捷键或呼出方式时，上方三张 SVG 交互图解即时联动刷新。

### 安装与升级

- **AGY Market 用户**：可直接在 AGY Market 侧栏检测更新并一键安装预构建 `.tar.gz` 发行包（自动通过 `.sha256` 校验并完整保留 `data/` 个人分组与设置）。
- **手动安装 / 升级**：下载下方 `agy-anchor-wheel-v0.12.0.zip`，解压后 Windows 用户双击 `install-plugin.cmd`、macOS / Linux 用户运行 `bash install-plugin.sh`，脚本会自动备份旧版并无损升级（保留 `data/`）；更新后在 Antigravity 插件管理列表将「锚点轮盘 · AnchorWheel」关闭再重新开启一次即可加载新版后端配置。
- **适配 Antigravity**：`2.34.0`（`2.34.x` 已实测，本地需 Node.js >= 22，推荐 >= 22.5 以启用 SQLite 预览；可选安装 `ffmpeg` 解锁 ProRes / HEVC / MKV / AVI 等视频自动转码与透明棋盘格预览）
