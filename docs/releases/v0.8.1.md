# v0.8.1 — 侧边栏文件夹直达系统资源管理器（溢出菜单补全、伴生条一键打开与目录树右键菜单）

<!-- aw-compat: agy=2.34.x -->

### 更新亮点

- **补齐原生侧栏文件夹 `⋮` 溢出菜单缺失的「打开系统文件夹」入口（Mode 1）**：
  - 解决 Antigravity 原生侧边栏打开文件夹时，右上角 `⋮` 更多操作菜单仅有「复制路径」而无法像普通文件一样直接打开系统资源管理器的问题。
  - 点击 `⋮` 菜单后自动在「复制路径」下方无缝补全匹配宿主语言与操作系统的原生风格菜单项（Windows：`在文件资源管理器中打开` / `Open in File Explorer`；macOS：`在访达中打开`；Linux：`在文件管理器中打开`）；若当前原生菜单已自带资源管理器入口（如常规文件视图），自动识别绝不重复注入。

- **顶部伴生条一键直达系统文件夹（1 次点击，无需展开二级菜单）**：
  - 在原生侧边栏顶部伴生条新增系统文件夹快捷入口：浏览文件夹时显示「**打开目录**」（窄屏下自动折叠为纯图标防溢出），浏览普通文件时显示轻量图标按钮一键在资源管理器中选中定位当前文件。

- **右侧工作区文件树、目录列表行与面包屑右键菜单补强**：
  - 针对 Antigravity 原生暂无右键菜单的右侧「工作区」文件树节点、文件夹列表行以及路径面包屑，新增原生风格浮层右键菜单，支持一键**在系统资源管理器中打开 / 定位**、**打开所在文件夹**、**复制路径**及**在侧边栏新标签页打开**，不干扰原有正文文本选中与顶部标签栏右键菜单。

- **跨平台安全后端与 Mode 2 独立工作台全量对齐**：
  - 新增 `system_explorer.mjs`（HTTP `POST /api/file/reveal` 与 CDP RPC `revealInExplorer`），安全处理含中文、空格、逗号的 Windows 路径与磁盘根目录（`explorer.exe` 精确传参，仅定位展示、不执行文件），同步支持 macOS（`open` / `open -R`）与 Linux（`xdg-open`），并强制拦截 UNC 网络路径与 `.env` / `.ssh` 等敏感凭据目录。
  - Mode 2 独立侧栏工作台同步在副栏与目录视图顶栏加入一键「打开目录 / 在资源管理器中打开」按钮。
  - 自动化回归测试扩展至 **36 项**（含无头 Chromium 模拟原生溢出菜单、语言自适应、去重校验及目录树右键菜单实测）。

### 安装与升级

- **AGY Market 用户**：可直接在 AGY Market 侧栏检测更新并一键安装预构建 `.tar.gz` 发行包（自动通过 `.sha256` 校验并完整保留 `data/` 个人分组与设置）。
- **手动安装 / 升级**：下载下方 `agy-anchor-wheel-v0.8.1.zip`，解压后双击 `install-plugin.cmd` 即可自动备份旧版并无损升级；安装后在 Antigravity 左侧「自定义扩展」将「锚点轮盘 · AnchorWheel」关闭再重新开启一次即可加载新版后端。
- **适配 Antigravity**：`2.34.0`（`2.34.x` 已实测，本地需 Node.js >= 22）
