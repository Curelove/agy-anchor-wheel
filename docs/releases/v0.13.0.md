# v0.13.0 — 主对话窗口 5 向布局轮盘（默认关闭按需开启）与全向扇区自定义

<!-- aw-compat: agy=2.34.x -->

### 更新亮点

- **新增主对话窗口 5 向「窗口布局」轮盘（默认关闭，按需开启）**：
  - **独立于右侧文档轮盘，互不混淆**：在「设置 → 交互模式与图解 → 进阶手势、防冲突与主对话布局轮盘」中勾选开启后，可在 Antigravity 原生主对话窗口空白处按住当前配置的鼠标触发键（默认中键，或已配置的 `Alt + 右键` / 侧键等组合）呼出独立的 5 向布局轮盘；圆心采用虚线内环与「**窗口布局**」实时状态摘要（如 `左开 · 概览` / `左收 · 右收`），与右侧文档导航轮盘在视觉与职责上彻底分离。
  - **开箱即用的 5 向默认布局与联动语义**：
    - **左上**：收起左侧边栏（已收起时自动半透明弱化、重复划选幂等无误触）
    - **左中**：展开右侧边栏（概览面板处于打开态时自动同步收起概览，提示 `并关概览`）
    - **左下**：展开 / 收起概览面板（概览开启时显示高亮圆点并切换为「收起概览」，非会话页自动禁用）
    - **右上**：展开左侧边栏（自动避开右侧栏同名按钮并解除右栏最大化）
    - **右下**：收起右侧边栏（若概览面板同时处于打开状态会一并收起）
  - **支持 5 个方位自由自定义与智能对调**：开启开关后原地展开「5 向扇区自定义」双列面板（左列左上/左中/左下、右列右上/右下），每个方位均可在 `收起左栏 / 展开左栏 / 切换左栏 / 展开右栏 / 收起右栏 / 切换右栏 / 概览面板 / 留空（无操作）` 中自由选择；改选已占用动作时自动与原方位对调，支持一键「**恢复默认**」。

- **主对话复杂界面的手势防误触与稳定性加固**：
  - **360° 无死区划分与清晰填充图标**：左半环三等分各 `60°`、右半环二等分各 `90°`，彻底消除正上/正下环内盲划死角；左右栏图标新增半透明侧栏填充色块与独立概览卡片图标，一眼区分控制目标；修复 CSS 入场动画覆盖禁用/已就绪态半透明弱化的问题。
  - **贴屏边呼出保护**：在聊天列左右留白或底部紧贴视口边缘呼出轮盘导致圆心钳制偏移时，原地松手强制取消不误触发；朝被钳制侧屏边划动时豁免外圈取消判定，边缘扇区同样可靠可达。
  - **主对话高危交互与跨平台全面避让**：划选聊天文字时自动放行无修饰右键复制与 `Shift + 左键` 扩选；全面排除输入框、按钮、`.xterm` 内嵌终端、`iframe`、音视频/画布、分屏分隔线、原生滚动条轨道与左侧边栏空白区域；修复 macOS 右键即时菜单时序、窗口失焦/`pointercancel`/原生拖拽残留、多会话分屏串台及原生浅色主题弹窗底色回退；Redux 动作分发后自动复核状态并在宿主改版静默失效时穿透回退官方 DOM 按钮。

### 安装与升级

- **AGY Market 用户**：可直接在 AGY Market 侧栏检测更新并一键安装预构建 `.tar.gz` 发行包（自动通过 `.sha256` 校验并完整保留 `data/` 个人分组与设置）。
- **手动安装 / 升级**：下载下方 `agy-anchor-wheel-v0.13.0.zip`，解压后 Windows 用户双击 `install-plugin.cmd`、macOS / Linux 用户运行 `bash install-plugin.sh`，脚本会自动备份旧版并无损升级（保留 `data/`）；更新后在 Antigravity 插件管理列表将「锚点轮盘 · AnchorWheel」关闭再重新开启一次即可加载新版配置与模块。
- **适配 Antigravity**：`2.34.0`（`2.34.x` 已实测，本地需 Node.js >= 22，推荐 >= 22.5 以启用 SQLite 预览；可选安装 `ffmpeg` 解锁 ProRes / HEVC / MKV / AVI 等视频自动转码与透明棋盘格预览）
