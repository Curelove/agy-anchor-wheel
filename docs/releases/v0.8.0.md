# v0.8.0 — 侧边栏通用文档阅读器（DOCX 旗舰预览、多格式办公文档与悬停快览）

<!-- aw-compat: agy=2.34.x -->

### 更新亮点

- **Antigravity 右侧栏 `.docx` 旗舰原生预览（Mode 1 + Mode 2 双模支持）**：
  - 彻底替代 Antigravity 原生侧边栏打开 Word 文档时的 `Preview is not available for this file type.` 空白不可预览页，零第三方依赖、纯本地 Node.js 解析渲染。
  - 完整还原 `styles.xml` 样式继承、`numbering.xml` 多级编号（含中文序号 `一、二、`、罗马/字母/项目符号）、合并单元格表格（`gridSpan` / `vMerge`）与问卷无框排版表、内嵌图片、安全超链接、脚注/尾注、批注、OMML 公式与修订记录（保留插入、过滤删除）。
  - 内置交互阅读工具栏：可折叠文档大纲目录（支持自动识别中文无样式标题）、文档内高亮查找（`Enter` / `Shift+Enter` 跳转）、**深色跟随 / A4 纸张模式**一键切换、纯文本一键复制、系统默认应用（Word / WPS）一键打开。
  - 在原生侧栏（Mode 1）保持零破坏宿主 React DOM、中键呼出双侧轮盘全透传、切换回原文后精准恢复滚动位置。

- **多格式办公与归档文档一站式扩展预览**：
  - **电子表格**：`.xlsx` / `.xlsm`（多工作表标签切换、共享字符串、合并单元格、日期序列转换、表内快速筛选）及 `.csv` / `.tsv`（自动编码检测与表格/源码切换）。
  - **演示文稿**：`.pptx`（按序幻灯片卡片、表格、内嵌图片与可折叠演讲者备注）。
  - **开放文档与电子书**：`.odt` / `.ods` / `.odp`、`.rtf`（含 GB18030/Big5/Shift-JIS 字符解码）、`.epub`（章节导航与净化渲染）、`.doc`（魔数识别伪装 DOCX/RTF/HTML 及 OLE2 文本回退）、`.zip`（零解压安全目录清单）与 `.pdf`（元信息与 Mode 2 内嵌阅读）。
  - **0.25 秒悬停快览升级**：轮盘与竖向层级树悬停 `.docx` / `.xlsx` / `.pptx` / `.rtf` / `.epub` / `.zip` 等文件时直接预览结构摘要与正文片段。

- **安全防护、自动化发布与质量验收**：
  - ZIP/XML 解析引擎内置防压缩炸弹配额（单条目 16MB / 累计 48MB）与路径穿越阻断；外部打开采用扩展名白名单与安全参数隔离。
  - 全量自动化测试扩展至 **30+ 项**（含无头 Chromium Mode 1 实测与 `1440×900` / `1100×860` / `390×844` 多视口视觉审计）。
  - 新增 `.github/workflows/release.yml` 自动发布流水线与本地 `npm run release:publish` 一键发版工具，后续推送 `v*` 标签即可自动测试、打包并发布 GitHub Release。

### 安装与升级

- **AGY Market 用户**：可直接在 AGY Market 侧栏检测更新并一键安装预构建 `.tar.gz` 发行包（自动通过 `.sha256` 校验并完整保留 `data/` 个人分组与设置）。
- **手动安装 / 升级**：下载下方 `agy-anchor-wheel-v0.8.0.zip`，解压后双击 `install-plugin.cmd` 即可自动备份旧版并无损升级。
- **适配 Antigravity**：`2.34.0`（`2.34.x` 已实测，本地需 Node.js >= 22）
