# v0.10.0 — 全格式视频侧边栏预览、轮盘触发按键自定义与非强制更新推送

<!-- aw-compat: agy=2.34.x -->

### 更新亮点

- **`.mov` 与全格式视频侧边栏直览（支持自动无损重封装与流式兼容转码）**：
  - **覆盖常见与专业剪辑视频封装**：完整支持 `.mov` / `.qt` / `.mp4` / `.m4v` / `.webm` / `.mkv` / `.avi` / `.flv` / `.f4v` / `.wmv` / `.asf` / `.ts` / `.mts` / `.m2ts` / `.mpg` / `.mpeg` / `.m2v` / `.3gp` / `.3g2` / `.ogv` / `.rmvb` / `.rm` / `.vob` / `.mxf` / `.divx` 共 25 种视频格式（同步补齐 `.aac` / `.opus` / `.wma` / `.aiff` 等 10 种音频格式）。
  - **智能四级播放策略与防黑屏兜底**：通过本地 `ffprobe` / `ffmpeg` 自动识别封装与编码——标准 H.264/VP9/AV1 浏览器兼容视频直接走零内存占用 HTTP `206 Partial Content` 字节区间流播放；`.mov` / `.mkv` / `.ts` 等容器内的 H.264 画面走亚秒级无损重封装（`-c:v copy`）不损失画质；对 Chromium 原生无法解码的 ProRes 4444（含 Alpha 透明通道）、HEVC 10-bit、DNxHR、AVI/WMV/RMVB/MXF 等编码自动后台转为兼容 MP4 缓存（4 分钟以上长片走实时分段流并支持进度跳转）；若检测到纯音频黑屏或 Webview CSP 限制，自动切换 Blob 兜底或给出清晰一键调用系统播放器入口。
  - **原生侧边栏自动接管（Native-First Auto-Yield）**：仅当 Antigravity 原生视图显示不可预览提示，或原生 `<video>` 报错 / 有声无画时自动接管播放；播放器工具栏内置倍速循环切换（`0.5×`～`2.0×`）、单曲循环、画面参数与透明通道提示，同时修复 10-bit 与透明通道 `.mov` 悬停缩略图生成失败问题。

- **轮盘触发鼠标按键自由配置（默认仍为鼠标中键）**：
  - 在「设置 → 交互模式与图解」新增「**轮盘触发鼠标按键**」选项，可在 **鼠标中键（默认）**、**鼠标右键**、**鼠标侧键 1（后退键）**、**鼠标侧键 2（前进键）** 之间随时切换，设置卡图解、提示文案与聚焦标签同步实时联动。
  - **零误触防冲突处理**：选择右键按住呼出时，短按右键仍完整保留原生右键菜单，按住呼出并松手后彻底拦截多余右键菜单弹出；选择任意侧键按住呼出时，仅拦截当前绑定侧键在右侧文档栏内的浏览器前进/后退动作，未绑定的另一枚侧键继续正常执行历史翻页。

- **检查更新全面体检 · 温和主动推送 + 按版本忽略**：
  - **修复两处更新检查隐蔽问题**：修正 Atom 源多条目解析逻辑，改为在所有条目中按语义化版本精确选取最高稳定版（避免旧版修订置顶误报）；修复独立工作台（Mode 2）启动时若本地已有旧缓存则跳过联网检查的问题，并在后端补充启动与每 6 小时周期后台检查。
  - **非强制推送，完全尊重用户节奏**：检测到未忽略的新版本时，在右侧栏顶部显示低调的「**新版 vX.Y.Z**」入口并在右下角弹出可关闭的非阻塞提醒卡片（提供「**查看更新**」「**稍后**」「**忽略此版本**」三个按钮）。
  - **按版本记忆忽略、下个新版自动恢复**：点击「**忽略此版本**」后，该版本的提示胶囊、设置角标与右下角推送卡片立即收起并持久化记录，不再打扰；当未来发布比已忽略版本更新的新版本时，更新提醒会自动恢复推送；也可随时在「设置 → 收纳与高级 → 版本更新与 Antigravity 适配」中手动检查或点击「**取消忽略**」。

### 安装与升级

- **AGY Market 用户**：可直接在 AGY Market 侧栏检测更新并一键安装预构建 `.tar.gz` 发行包（自动通过 `.sha256` 校验并完整保留 `data/` 个人分组与设置）。
- **手动安装 / 升级**：下载下方 `agy-anchor-wheel-v0.10.0.zip`，解压后双击 `install-plugin.cmd` 即可自动备份旧版并无损升级；安装后在 Antigravity 左侧「自定义扩展」将「锚点轮盘 · AnchorWheel」关闭再重新开启一次即可加载新版后端。
- **适配 Antigravity**：`2.34.0`（`2.34.x` 已实测，本地需 Node.js >= 22；安装 `ffmpeg` 可解锁非 H.264 编码如 ProRes/HEVC/AVI/WMV/MKV 等侧边栏自动转码直览）
