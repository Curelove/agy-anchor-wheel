# 锚点轮盘（AnchorWheel）新增功能分步操作说明

本文档说明本次更新新增的四项界面功能：**侧边栏直接编辑文档并让 AI 查看修改记录**、**右侧栏选中文字快捷右键菜单**、**双侧轮盘分类上下拖动排序**，以及**音浪圆球动态效果与设置页清理**。

---

## 一、首次生效步骤：刷新本机插件后台服务（仅需执行一次）

由于本次更新包含新的本地保存与编辑记录后台服务，代码已部署到本机插件目录，首次使用前需要重新开关一次插件以加载新版后台：

1. **打开插件管理页**：在当前聊天回复中左键单击插件卡片链接，或点击 Antigravity 窗口左侧活动栏底部的插件图标，在已安装列表中找到「**锚点轮盘 · AnchorWheel**」。
2. **重启插件后台**：在插件详情页右上角找到启用开关，**鼠标左键单击关闭一次，停顿 1 秒后再左键单击重新打开**。
   - **正常画面变化**：右侧边栏文档顶部（标签栏正下方、文件路径面包屑上方）重新出现一行浅灰细条工具栏，最右侧带有齿轮状「设置」图标按钮。

---

## 二、在右侧边栏直接编辑文档并让 AI 查看修改记录

打开 `.md`、`.txt`、`.json`、`.jsonl`、`.yaml`、`.csv` 或常规代码文本时，默认依然保持 Antigravity 官方页面不变；仅在你主动进入编辑时才切换为编辑器。

1. **进入侧边栏编辑**：
   - **位置锚点**：看向 Antigravity 窗口**右侧边栏顶部**、标签栏下方的插件细条工具栏右侧区域（紧邻「**层级**」按钮左侧）。
   - **鼠标动作**：**左键单击**带铅笔图标的「**编辑**」按钮。
   - **画面变化**：下方官方只读页面切换为带左侧行号列的文本编辑区；顶部状态栏左侧亮起绿色圆点并显示「**已保存 · 与磁盘一致**」，原「编辑」按钮文字变为蓝色高亮的「**正在编辑**」。
2. **直接输入与自动保存**：
   - **操作动作**：在下方文本编辑区内**左键单击**定位光标并直接打字修改；停笔约半秒（`0.65` 秒）后自动写入原文件，也可随时按键盘 `Ctrl + S`（请确保不处于中文候选词未上屏状态）立即保存。
   - **画面变化**：
     - 普通文档或结构完整的 `.json` 文件：左上角圆点变绿，文字更新为「**已自动保存 · 时:分:秒**」，右上角「**修改记录**」按钮自动加上括号数字（例如「**修改记录 (1)**」）。
     - 若编辑 `.json` 时括号、引号或逗号尚未补全：左上角圆点变为醒目暖黄色，文字提示「**JSON 格式待闭合（第 X 行附近），补全后自动保存**」，此时不会把半截损坏的 JSON 写进硬盘；补齐括号后会自动恢复保存（如确需原样写入，可左键单击提示右侧的「**强制保存**」胶囊按钮）。
3. **辅助排版与查找替换**：
   - 编辑 `.json` 文件时，**左键单击**编辑器顶栏右侧的「**格式化**」按钮，可一键自动整理两格缩进。
   - **左键单击**「**换行**」按钮可切换长行自动折行；**左键单击**「**查找替换**」按钮（或在编辑区内切英文输入法按 `Ctrl + F` / `Ctrl + H`）可在顶部展开双行查找与替换栏。
4. **让 AI 查看你的修改记录（两种方式任选）**：
   - **方式 A（直接口头提问，无需点按钮）**：保存修改后，直接在左侧聊天输入框告诉 AI「看看我刚才在侧边栏改了什么」，AI 会通过内置技能自动读取插件生成的最近修改记录文件。
   - **方式 B（手动查看差异并一键填入对话框）**：
     1. 在右侧编辑器顶栏右上方（紧邻「**退出编辑**」按钮左侧），**左键单击**「**修改记录 (1)**」按钮。
     2. 编辑器上半部分会展开修改对比抽屉，绿色底行（`+`）代表新增内容，红色底行（`-`）代表删除内容。
     3. **左键单击**记录卡片右上角实心主色按钮「**发给 AI 查看**」。
     4. **画面变化**：左侧聊天输入框内会自动填入 `@文件名` 与带行号的修改对比代码块，你只需补充一句说明或直接发送即可。
5. **返回官方默认页面**：
   - **鼠标动作**：**左键单击**编辑器顶栏最右侧的「**退出编辑**」按钮（或再次左键单击上方插件栏的「**正在编辑**」按钮）。
   - **画面变化**：编辑器收起，立即恢复 Antigravity 官方默认页面（若当前仍有未闭合的草稿未保存，顶部会先弹出提示条让你选择「继续编辑」「放弃未存改动并退出」或「强制保存并退出」）。

## 三、右侧栏选中文字后的快捷右键菜单

为避免改动左侧聊天消息内容引发对话上下文错乱，也避免与 `obsidian-prism` 插件的文件链接右键菜单冲突，本菜单**仅在右侧边栏选中普通正文或代码文字时出现**：

1. **触发动作**：在窗口**右侧边栏**的文档正文或代码块中，**按住鼠标左键拖动选中一段文字**，然后在选中文字上方**单击鼠标右键**。
   - **画面变化**：光标旁弹出圆角快捷菜单，顶部显示当前文件名与选中文本所在行号。
2. **菜单项说明**：
   - **左键单击「复制选中内容」**：将选中文字复制到系统剪贴板。
   - **左键单击「引用选中片段到输入框」**：自动将 `@文件名（行号）` 与引用格式包裹的选中文字填入左侧聊天输入框，无需手动来回复制粘贴。
   - **左键单击「进入编辑并定位到此段」**（可编辑文本文件显示）：直接打开侧边栏编辑器，自动滚动并高亮选中刚才那段文字，方便立刻修改。
   - **左键单击「复制文件路径」**：复制当前文件的本地完整路径。
   - **补充说明**：若你需要打开浏览器原生右键菜单，按住键盘 `Shift` 再**单击鼠标右键**即可直接放行原生菜单。

## 四、拖动调整轮盘分类顺序与开启「音浪圆球」动态效果

1. **打开设置弹窗**：
   - **位置锚点**：看向右侧边栏顶部插件工具栏**最右端**（或独立「锚点轮盘工作台」顶栏右上角）。
   - **鼠标动作**：**左键单击**齿轮图标按钮。
   - **画面变化**：屏幕中央弹出「**锚点轮盘设置与交互图解**」窗口。
2. **上下拖动调整双侧轮盘分类顺序**：
   - 在设置窗口顶栏中间标签组中，**左键单击**中间的「**分类与预览**」按钮。
   - 看向下方「**双侧轮盘自定义分类规则**」卡片：每条分类行**最左侧**现在都有一列六点手柄图标（`⋮⋮`）。
   - **拖动动作**：将光标移到某一行最左侧的 `⋮⋮` 手柄上（光标变为手掌抓握形状），**按住鼠标左键不放并向上或向下拖动**，跨过相邻行中线时两行会即时互换位置；松开左键即完成排序（最底部的「**其他**」固定在末尾兜底）。
   - **画面变化**：拖动过程中，窗口上方的双侧轮盘示意图扇区顺序会同步实时重排；点击窗口右下角「**保存并应用**」后正式生效。
3. **切换「音浪圆球」主题或在现有主题上单独开启音浪动态效果**：
   - 在设置窗口顶栏中间标签组中，**左键单击**右侧的「**收纳与高级**」按钮（原顶部容易让人误以为切换了模式的「母页轮盘」示意图已移除，第一组即为「**界面外观**」）。
   - **方式 A（切换整套深色声波主题）**：在「**界面主题（适配 obsidian-prism）**」右侧下拉框中**左键单击**，选择「**音浪圆球（深色动态）**」（此主题下音浪球动态效果默认开启且保持常驻）。
   - **方式 B（保留暖白画册等其他主题，按主题单独开启并记忆）**：其他主题下「**开启轮盘音浪球动态效果**」默认关闭；若希望在「**暖白画册**」或某一主题下叠加音浪动态效果，可在下方紧邻的复选框**左键单击勾选**，系统会按每个主题分别记忆你的开关状态。
   - **左键单击**窗口右下角「**保存并应用**」按钮关闭设置。
   - **呼出轮盘时的画面变化**：在右侧边栏按住轮盘触发键（如鼠标中键）呼出轮盘后，光标停留在中心圆环内时，圆心驻波环与轮盘外沿保持平稳柔和的呼吸起伏；当光标偏向任意一侧时，对应侧的轮盘扇区轮廓会平滑鼓起涌动，并自然生长出交错起伏的多层液态音浪、扇区内部声波涟漪与高光波峰（高度严格限制在安全上限内，二级列表展开方向自动避让，不会遮挡扇区文字）。
